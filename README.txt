語音導覽
全站 16 段女性聲音預製 MP3。2026-10-13 更新 10 段內容有變動或新增的短解說，其他 6 段保留。安東文化館依使用者確認改為「生平事蹟與教導」。訪客無須配音服務帳號或 API 金鑰。網站介面只標示「語音導覽」或「導覽解說」，不顯示聲線名稱。

自動播放解說預設開啟，導覽區有清楚的開關，捲動到解說內容或切換景點時播放；設定保存在訪客自己的瀏覽器，重新整理後仍保留。每次選定景點只自動播放一次，避免捲動來回或手動暫停後反覆播放。離開解說內容、切站或關閉開關會停止目前解說。關閉自動播放時仍可手動點「聆聽解說」。

有聲播放遵循瀏覽器規則。首次禁止自動播放時，頁面顯示「啟用聲音」，訪客點一次即可播放目前景點，後續切換共用同一個音訊播放器。點首頁的「開啟沉浸式導覽」也會在自動播放開啟時啟動解說。訪客切到其他分頁或離開頁面會停止音訊。

網站具暫停、繼續、語速調整、切站停止功能；語音與影片播放時互斥。頁面建議解說時間是現場導覽建議，MP3 是景點故事短解說。老母殿 10 分鐘不含母燈陞座。

建設歷程影片
「老前人尋聖地」改用本機完成的滿版、描邊字幕及漸變修訂版影片，直接由網站提供 MP4。原生播放器沒有 YouTube 標誌、頻道資訊或推薦影片。支援播放、暫停、拖曳與全螢幕；手機保留4:3版面、可原地播放，影片不自動播放，按下播放後才載入影片。

網站版本保留1440×1080、30fps與原片9548幀，長度318.323秒；原AAC音軌直接保留，音樂節奏不變。網站檔案約63MB，使用faststart加速開始播放。影片位於video/elder-journey-20261013.mp4，封面位於assets/elder-journey-poster.jpg。先前video/elder-kindness.mp4只保留為歷史素材，不再由網頁播放。
